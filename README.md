# RSR - The Main Community Hub

An interactive cosmic community web experience featuring procedural Web Audio synthesis, a dynamic Cyan Vortex physics simulation, mobile gyroscope 3D perspective tilt, and live Discord/Telegram community hubs.

## Quick Start (Auto-Bootstrap)

Whenever exported to a local machine, VS Code, or GitHub Codespaces:

### Option 1: Development Server (Instant Auto-Preview)
```bash
npm install
npm run dev
```
> The development server will launch on `http://localhost:3000` and **automatically open your browser to the preview tab**.

### Option 2: Production Server (Auto-Build & Launch)
```bash
npm start
```
> Automatically verifies and builds production assets if `dist/` is not present, starts the Express server, and opens your browser.

### Option 3: VS Code / GitHub Codespaces
Opening this project folder automatically triggers the background bootstrap task (`.vscode/tasks.json`) and forwards port 3000 with auto-browser preview enabled.
